## 2024-05-18 - Optimize Math distance calculations in tight game loops
**Learning:** Using `Math.pow(x, 2)` instead of direct multiplication (`x * x`) introduces significant overhead in Javascript, especially inside critical hot paths like distance calculations in a game engine's `requestAnimationFrame` loop. Moreover, doing `Math.sqrt` and immediately squaring it later (e.g. `dist(v, w) * dist(v, w)`) calculates unnecessary square roots that can be entirely bypassed with a `distSq` (squared distance) function.
**Action:** When calculating distances, prefer computing standard squared distances (`dx * dx + dy * dy`) and skip square roots completely where you only need the square (like when checking bounds against squared thresholds or calculating projections). Never use `Math.pow` for simple small integers.
