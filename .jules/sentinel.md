## 2026-08-29 - [CRITICAL] Prevent Backend Secrets Leakage via Vite config
**Vulnerability:** The `vite.config.ts` file used `define` to inject `process.env.API_KEY` and `process.env.GEMINI_API_KEY` mapping to `loadEnv(mode, '.', '').GEMINI_API_KEY` directly into the frontend build. This exposes sensitive backend API keys to anyone inspecting the client-side JavaScript bundle.
**Learning:** Frontend build tools like Vite's `define` or Webpack's `DefinePlugin` physically replace matched variables in the source code with the provided string values during compilation. If a backend secret is passed to these plugins, it becomes hardcoded in the public assets. In a client-side environment, no secret is truly hidden.
**Prevention:** Never use `define` or environment variable injection plugins to provide backend secrets (like API keys, database credentials, or private tokens) to a frontend bundle. Ensure that only public, non-sensitive configuration is injected into the client environment. If the frontend needs to use an API requiring a secret, the request should be routed through a secure backend proxy.
